## Utiliser des images depuis Docker Hub

- Pour faciliter le déroulement du workshop, nous avons préalablement buildé les images de DockerCoins

- Nous avons pushé ces images sur le Docker Hub, sous le compte utilisateur [dockercoins](https://hub.docker.com/u/dockercoins)

- Ces images sont *taguées* avec un numéro de version, `v0.1`

- Les noms complets des images sont donc :

  - `dockercoins/hasher:v0.1`

  - `dockercoins/rng:v0.1`

  - `dockercoins/webui:v0.1`

  - `dockercoins/worker:v0.1`

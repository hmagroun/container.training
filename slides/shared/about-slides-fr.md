## Slides ≠ documentation

* Nous nous sommes efforcés d'inclure beaucoup d'informations dans ces slides

* Mais elles ne remplacent ni ne concurrencent la documentation officielle !

* Considérez ces slides comme un support supplémentaire pour accompagner votre apprentissage

* N'hésitez pas à consulter fréquemment les documentations officielles

  ([Documentation Docker][docker-docs], [Documentation Kubernetes][k8s-docs])

* Ainsi que les communautés en ligne

  (par ex. : [Forums Docker][docker-forums], [Docker sur StackOverflow][docker-so], [Kubernetes sur StackOverflow][k8s-so])
